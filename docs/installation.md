1. Install the plugin from the registry and approve its permissions: it reads your content and calls `www.revid.ai`.
2. Open **Revid videos** in the admin and paste an API key from [revid.ai/account](https://www.revid.ai/account) (API tab). Making videos needs a Revid plan and uses its credits.
3. Pick the aspect ratio and target length, and turn on automatic videos if you want one per new post.
4. To give your site's AI agent the tools, enable this plugin's MCP tools in the MCP settings.
